# React Best Practices

When generating, modifying, or reviewing any React/JSX code, consult the `react-best-practices` skill at `.claude/skills/react-best-practices/skill.md` to ensure best practices are followed.

This applies to all work in this project — components, hooks, state management, performance, bundle size, and rendering. Reach for the skill before non-trivial React work, not just when explicitly asked.
